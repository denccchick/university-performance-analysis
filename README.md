# Анализ успеваемости студентов направления ПИН


Аналитическое исследование, посвященное сравнению успеваемости студентов двух разных учебных планов по направлению "Программная инженерия". Цель — оценить влияние изменений в учебном плане на результаты сдачи математических дисциплин с учетом начальной подготовки студентов.

##  О проекте

Данный проект представляет собой полноценное статистическое исследование, выполненное в рамках учебной работы. В ходе анализа были применены современные методы обработки данных и проверки статистических гипотез для сравнения успеваемости двух групп студентов, обучающихся по разным учебным планам.

**Ключевые аспекты исследования:**
*   Учет начальной подготовки студентов через анализ результатов первого семестра
*   Сравнительный анализ по 6 ключевым математическим дисциплинам
*   Применение bootstrap-тестов, Z-тестов и теста Левене для проверки гипотез
*   Анализ поляризации успеваемости среди студентов


**Основная цель:** Провести сравнительный анализ успеваемости студентов, обучающихся по разным планам, с учетом их начальной подготовки.


## Технологии и инструменты

*   **Язык программирования:** Python 3.x
*   **Основные библиотеки:**
    *   `pandas` - обработка и анализ данных
    *   `numpy` - численные вычисления
    *   `matplotlib` / `seaborn` - визуализация данных
    *   `scipy.stats` - статистические тесты
*   **Среда разработки:** Jupyter Notebook
*   **Методы анализа:**
    *   Описательная статистика (медиана, дисперсия, асимметрия)
    *   Проверка статистических гипотез (bootstrap, Z-тест, тест Левене)
    *   Визуализация распределений (гистограммы, боксплоты)
    *   Сравнение долей и средних значений
